Instant Attack - Fabric 1.20.1 (client-side)

Build:
  1. Install JDK 17.
  2. In this folder run:   gradle wrapper --gradle-version 8.7
  3. Then:                ./gradlew build        (Windows: gradlew.bat build)
  4. Jar is in build/libs/instant-attack-1.0.0.jar -> put in your mods folder.
Needs only Fabric Loader (no Fabric API).
